Description of files and folders:

input_files : contains raw data that was used for the analysis
	shootout_data.csv : the list of shootouts with shot by shot data on the outcome of each shot and the details of the game
	aph_competition_mapping.csv : A mapping of competition ID's from our dataset to that used in the APH paper
	international_competitions.csv : A classification of the competitions in our data as international or club tournaments


output files: All the output files generated by the code are written here. It contains CSV representations of the results values generated from the R Code.

bootstrapping : contains intermediate output files from bootstrapping observed data


------------------------------------------------------------------------------------------------------------------------------------------

Software requirements:
R-3.4.4 or later with the following packages:
	plyr
	sqldf
        markovchain
        dplyr


1. Overview:

-This document provides step-by-step instructions to execute the Penalty Shootout Analysis Pipeline using RStudio or any R-compatible IDE. 
-The analysis processes historical penalty shootout data, performs bootstrapping, applies Bayesian updating, and simulates different penalty sequences to evaluate fairness.

2. Prerequisites:

2.1 Required Software:
-R (Version 4.4.2 or higher)
-RStudio (Optional, but recommended)

2.2 Required R Packages:
-Ensure that the following R packages are installed. If not, install them by running:

 install.packages(c("plyr", "sqldf", "markovchain", "dplyr"))

-Alternatively, install them one by one:

 install.packages("plyr")
 install.packages("sqldf")
 install.packages("markovchain")
 install.packages("dplyr")

3. Project Folder Structure:
-Ensure that the project directory contains the following structure before running the scripts:

Penalty_Shootout_Analysis/
│── input_files/                  # Contains input datasets (CSV files)
│   │── shootout_data.csv
│   │── aph_competition_mapping.csv
│   │── international_competitions.csv
│── bootstrap/                     # Stores bootstrapped simulation outputs
│── output_files/                   # Stores final results after execution
│── analysis_pipeline.R             # Main R script to execute the full analysis


4. Running the R Script:

4.1 Opening the Project in RStudio:

  1.Open RStudio (or any R-compatible IDE).
  2.Set the working directory to the project folder. In RStudio, run the following command in the Console:
  
  setwd("C:/path/to/Penalty_Shootout_Analysis")  # Change this to your actual folder path

4.2 Running the Analysis:

 Method 1: Running the Entire Script Automatically
 -To execute the entire analysis pipeline at once, run:

   source("analysis_pipeline.R")
 
 This will automatically:

 1.Load the datasets.
 2.Perform data preprocessing.
 3.Run bootstrapping to generate synthetic shootout data.
 4.Apply Bayesian updating.

 or Method 2: Running the Script Step-by-Step in RStudio:

 -For users who prefer executing code in sections, open analysis_pipeline.R in RStudio and run each block sequentially.

5. Where to Find the Results:

-Once the script execution is complete, the results will be stored in the output_files/ folder. The key output file is:

  output_files/final_results.csv – Contains the computed winning probabilities for different penalty shootout sequences.
